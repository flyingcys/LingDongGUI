- S1 已完成：
  - `runtime.h` 已固定为唯一 canonical 启动头：直接暴露 `tinyui_*` 原生声明（不再使用 `#define` alias 或 `static inline` wrapper）
  - `tinyui_init()` / `tinyui_deinit()` / `tinyui_screen_create()` / `tinyui_screen_load()` / `tinyui_timer_handler()` 已作为 canonical 启动序列
  - `app.h` 已标记为 INTERNAL / NON-CANONICAL，明确禁止新代码使用
  - `runtime.c` 已从内部依赖 `picoui_app_create()`/`picoui_app_set_window()` 等旧路径工作，不再通过 public app.h 获取声明
  - `tinyui/demo/main.c` unified runner 骨架已建立，待 S3 接入 demo build API
  - 全量编译测试通过，contract tests 已更新
- S2 已完成：
  - `tinyui/src/backend/ldgui/backend.h` 已拆散并删除
  - 所有内容已按职责迁入新 internal 头：`runtime_internal.h`（widget tree / app state / shared enums / layout cache）、`internal.h`（forward declarations）
  - widget-specific backend bridge helpers 保留在各 widget `.c` 文件内（定义先于使用，自声明）
  - `internal.h` 已改为 `#include "runtime_internal.h"`，不再依赖 `backend.h`
  - 原 19 处 `#include "backend.h"` / `#include "../backend/ldgui/backend.h"` 已清理为零
  - 全量编译测试通过
- S3 部分完成：
  - `tinyui/demo/basic_widgets/main.c` 已拆为 `basic_widgets.h` + `basic_widgets.c`，只暴露 `tinyui_demo_basic_widgets_build()` build API
  - `tinyui/demo/settings_panel/main.c` 已拆为 `settings_panel.h` + `settings_panel.c`，只暴露 `tinyui_demo_settings_panel_build()` build API
  - `tinyui/demo/main.c` unified runner 已接入 demo build API（默认 basic_widgets，支持编译宏切换 settings_panel）
  - CMake wiring 已更新：`add_tinyui_demo` 支持多源文件，各 demo target 使用 unified runner + demo build 文件
  - focused gate 已通过：`rtk ctest --test-dir build --output-on-failure -R 'test_tinyui|check_tinyui'`
  - `basic_widgets/` 和 `settings_panel/` 子目录不再有 `main()` / `run_demo()` / `picoui_app_*`
  - 其他 demo 保持旧结构，待后续阶段迁移
