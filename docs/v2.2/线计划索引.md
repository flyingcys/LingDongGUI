  - startup / `backend.h` / demo residue 面已冻结
  - 28 个 demo 目录均有 `main.c` + `tinyui_app_*` 依赖
  - 19 处 `backend.h` 直接 include 已记录
  - S1-S3 不得再重新定义起跑边界
- S1 已完成：
  - `runtime.h` 已固定为唯一 canonical 启动头：直接暴露 `tinyui_*` 原生声明（不再使用 `#define` alias 或 `static inline` wrapper）
  - `tinyui_init()` / `tinyui_deinit()` / `tinyui_screen_create()` / `tinyui_screen_load()` / `tinyui_timer_handler()` 已作为 canonical 启动序列
  - `app.h` 已标记为 INTERNAL / NON-CANONICAL，明确禁止新代码使用
  - `runtime.c` 已从内部依赖 `tinyui_app_create()`/`tinyui_app_set_window()` 等旧路径工作，不再通过 public app.h 获取声明
  - S1 阶段 `tinyui/demo/main.c` unified runner 骨架已建立（后在 S3 重构为 `tinyui_demo/main.c`，原文件已删除）
  - 全量编译测试通过，contract tests 已更新
- S2 已完成：
  - `tinyui/src/backend/ldgui/backend.h` 已拆散并删除
  - 所有内容已按职责迁入新 internal 头：`runtime_internal.h`（widget tree / app state / shared enums / layout cache）、`internal.h`（forward declarations）
  - widget-specific backend bridge helpers 保留在各 widget `.c` 文件内（定义先于使用，自声明）
  - `internal.h` 已改为 `#include "runtime_internal.h"`，不再依赖 `backend.h`
  - 原 19 处 `#include "backend.h"` / `#include "../backend/ldgui/backend.h"` 已清理为零
  - 全量编译测试通过
- S3 已完成（2026-06-13 关闭，2026-06-13 重构为 lv_demos.c 风格）：
  - 全部 28 个 demo 均已迁移为 LVGL-like 结构：每个 demo 只暴露 `void tinyui_demo_<name>(void)`，与 `lv_demo_widgets()` 调用约定完全一致
  - `tinyui/demo/tinyui_demos.c`：镜像 `lv_demos.c`，维护 name→函数表，提供 `tinyui_demos_create(argv+1, argc-1)` 运行时 dispatch
  - `tinyui/demo/tinyui_demos.h`：声明所有 28 个 demo 函数 + `tinyui_demos_create()` + `tinyui_demos_show_help()`；不使用 `#define tinyui_demo_run()` 宏
  - `tinyui_demo/main.c`（根目录）：唯一入口，调用 `tinyui_demos_create(argv+1, argc-1)` 选择 demo
  - `tinyui/demo/main.c` 旧 unified runner 已删除
  - 切换 demo 方式：运行时传参 `./tinyui_demo arc_basic`；无参数输出 demo 列表
  - cmake：28 个独立 target 合并为单一 `tinyui_demo` 可执行文件（所有 demo `.c` 编译进去）
  - S3 关门 gate 已通过：`rg -n 'tinyui_app_create|tinyui_app_run|run_demo\(|int main\(' tinyui/demo -g '!**/main.c'` 零匹配
  - 构建修复：初始化 `Arm-2D` 和 `perf_counter` 子模块；修复 `tinyui/src/core/event.c` 和 `runtime_bridge.c` 中多余一层 `../` 的相对路径；添加 `--start-group/--end-group` 解决 `tinyui_core ↔ tinyui_backend_ldgui_runtime` 和 `longdonggui ↔ longdonggui_porting_default` 循环依赖；`tinyui_demo/vt_mutex_stubs.c` 提供强定义解决 LTO 下 `VT_enter/leave_global_mutex` 弱符号链接问题
