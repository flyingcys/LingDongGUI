## 当前进度

- 当前状态：`v2.2` spec 已建立，implementation plan 待执行
- 已有事实：
  - `v2.1` 已完成；`v2.2` 不是 `v2.1` 未完成补丁，而是后续版本线
  - `runtime.h` 当前已存在 `tinyui_init/screen_create/screen_load/timer_handler/deinit` 风格入口，但仍保留 alias/旧叙事并存
  - `app.h` / `app.c` 当前仍保留旧 `picoui_app_*` 主路径
  - `tinyui/src/backend/ldgui/backend.h` 当前仍存在，且仍被部分 widgets 直接 include
  - 主线 demo 当前仍多为各自自带 `main()/run_demo()` 的结构，尚未统一成 LVGL-like runner
- 当前完成定义以 `docs/v2.2/2026-06-13-tinyui-v2-2-lvgl-like-startup-spec.md` 为准，不得回退到“保留旧 app 主路径兼容”或“保留 backend 总头”这类旧边界
