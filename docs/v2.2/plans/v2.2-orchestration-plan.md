# TinyUI v2.2 LVGL-Like Startup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `v2.1` 完成基础上，把 TinyUI 的开发者主路径收口到接近 LVGL 的方式：统一 runtime 启动骨架、删除 `backend.h`、让 demo `.c` 只导出 build API，并建立统一 runner。

**Architecture:** 严格按 `S0 -> S1 -> S2 -> S3` 串行推进。先冻结启动残留面和 `backend.h` 依赖分布，再把 canonical 启动路径收口到 `runtime.h`，随后拆散并删除 `backend.h`，最后把 demo 改成 LVGL-like 结构：demo 只 build UI，统一 `main` 持有 `init/load/loop/deinit`。

**Tech Stack:** C11、CMake、CTest、Python 3、SDL2、TinyUI runtime/core/widgets、现有 `LingDongGUI` backend binding。
