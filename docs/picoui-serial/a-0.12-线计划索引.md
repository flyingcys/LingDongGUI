## a-0.12 线定位

`a-0.12` 是 PicoUI `base` 剩余 `16` 个 strict direct public API parity 缺口的实现线。

`a-0.11` 已确认：当前仍未达到 strict `100% direct public API parity`，剩余候选全部位于 `base`：

1. geometry/alignment：`ldBaseAlignRegionCenter`、`ldBaseAutoVerticalGridAlign`、`ldBaseGetAbsoluteLocation`、`ldBaseGetAlignRegion`、`ldBaseGetRelativeLocation`
2. focus：`ldBaseFocusNavigate`、`ldBaseFocusNavigateInit`
3. tree traversal：`ldBaseGetChildCount`、`ldBaseGetChildList`、`ldBaseGetNextSibling`、`ldBaseGetParent`、`ldBaseGetRootNode`
4. name/type lookup：`ldBaseGetNameId`、`ldBaseGetWidget`、`ldBaseGetWidgetById`、`ldBaseGetWidgetType`

## a-0.12 做什么

1. 设计 portable PicoUI public API，覆盖 `base` 的 `16` 个剩余缺口。
2. 不直接暴露 `ldBase_t`、`ld_scene_t`、`arm_2d_*` 或 `ldWidgetType_t`。
3. 为新 API 补 unit test/backend proof。
4. 将对应 matrix/ledger/inventory 行从 `allowlisted` 更新为 `covered`。
5. 更新 `docs/ability/README.md` 和 `docs/ability/base.md`，把剩余缺口候选收敛到 `0`。

## a-0.12 不做什么

1. 不把 `policy_never_public=191` 纳入实现范围。
2. 不修改 LingDongGUI native API。
3. 不在 demo 里绕过 API 补 fake proof。
4. 不把 native 内部类型泄漏成 PicoUI public 类型。

## 串行阶段

1. `T0`：spec/plan/index
   - 创建 a-0.12 serial index、spec、plan。
2. `T1`：portable base API
   - 在 `picoui/include/picoui/widget.h` 定义 `picoui_point`、`picoui_size`、`picoui_rect`、`picoui_widget_type` 与 tree/name/type/geometry/focus public API。
3. `T2`：core/backend implementation
   - 在 `picoui/src/core/widget.c` 与 `backend_widget_tree.c` 实现查询和 helper，不泄漏 native 指针。
4. `T3`：unit proof
   - 在 `tests/picoui/unit/test_picoui_layout.c` 增加 native round-trip proof。
5. `T4`：contract matrix/docs
   - 同步三份 JSON truth-source 与 `docs/ability/*`。
6. `T5`：gate/review closeout
   - 跑 contract/unit/gate、GitNexus detect_changes、fresh review。

## 完成定义

`a-0.12` 完成时必须满足：

1. `base` 的 `optional_public_extension` 从 `16` 降为 `0`。
2. `covered` 从 `404` 增加到 `420`，`allowlisted` 从 `207` 降到 `191`。
3. `direct_public_covered_total=420`、`policy_allowlisted_total=191`。
4. `direct_public_100_complete=true`，但仅表示 strict direct public API parity 当前已覆盖 `base` 剩余候选；不代表人工视觉验收。
5. 所有新增 public API 都有 header/source/unit/matrix/docs 证据。
