## a-0.11 线定位

`a-0.11` 是 PicoUI direct public API 100% 目标下的 `base` 剩余缺口候选确认线。

`a-0.10` 已完成 public API truth gate 与 direct-100 文档化：

1. `covered` 行必须反查 `picoui/include` public header。
2. 当前事实是 `covered=404 / allowlisted=207 / missing_gap_total=0`。
3. `missing_gap_total=0` 只表示 native API 全量建账，不表示 direct public API 100%。
4. `207` 个 allowlisted 行已分层为 `policy_never_public=191`、`optional_public_extension=16`、`direct_100_required_if_user_demands=0`。

2026-06-02 fresh subagent 重新审计后确认：如果目标按用户要求提升为“100% direct public API parity”，`optional_public_extension=16` 不能只写成未来增强；它们必须在 docs/ability 中明确标为尚未对外 direct covered 的剩余缺口候选。

## a-0.11 做什么

1. 将这次 fresh subagent 审计结论正式落到 a-0.11 文档。
2. 明确当前仍未达到 100% direct public API parity。
3. 将 `base` 下 `16` 个 `optional_public_extension` 行列为 direct 100% 目标下的剩余缺口候选：
   - `ldBaseAlignRegionCenter`
   - `ldBaseAutoVerticalGridAlign`
   - `ldBaseFocusNavigate`
   - `ldBaseFocusNavigateInit`
   - `ldBaseGetAbsoluteLocation`
   - `ldBaseGetAlignRegion`
   - `ldBaseGetChildCount`
   - `ldBaseGetChildList`
   - `ldBaseGetNameId`
   - `ldBaseGetNextSibling`
   - `ldBaseGetParent`
   - `ldBaseGetRelativeLocation`
   - `ldBaseGetRootNode`
   - `ldBaseGetWidget`
   - `ldBaseGetWidgetById`
   - `ldBaseGetWidgetType`
4. 更新 `docs/ability/README.md` 和 `docs/ability/base.md`，避免读者把 `direct_100_required_if_user_demands=0` 误读成 direct 100% 已完成。
5. 为后续真正实现 100% direct public API parity 拆出可交给 subagent 的执行阶段。

## a-0.11 不做什么

1. 不在本线直接新增 PicoUI public API。
2. 不把 `optional_public_extension` 改成 `covered`。
3. 不把 `policy_never_public=191` 重新纳入 direct public API 缺口。
4. 不修改 LingDongGUI native API。
5. 不用截图、demo 或 manual artifact 证明 public API parity。

## a-0.11 当前结论

截至 2026-06-02，本线已完成当前确认与文档拆分。当前真实结论是：

1. PicoUI 仍未达到 strict 100% direct public API parity。
