## a-0.10 线定位

`a-0.10` 是 PicoUI public API truth 与 direct-100 gap review 线。

`a-0.9` 已完成 allowlist policy truth closeout：

1. `src/gui/ld*.h` public API inventory 仍为 `611` 行。
2. matrix 当前为 `covered=404 / allowlisted=207 / missing_gap_total=0`。
3. 所有 matrix group 当前为 `policy_complete_not_direct_100` 或 `non_widget_policy_complete`。
4. 这只能证明 policy ledger 完整，不能证明 PicoUI 对外 public API direct 100% 覆盖 LingDongGUI native API。

`a-0.10` 的起点来自 2026-06-02 fresh subagent 复核：`docs/ability` 与三份 contract JSON 中有 `28` 个 `covered` 行曾写入不存在的 PicoUI public API 名。已修正为当前 `picoui/include` 真实 public API 名，并给 `check_picoui_release_capability_matrix.py` 增加 public header 反查，防止再次把想象 API 写成 `covered`。

## a-0.10 做什么

1. 将“public API 名必须真实存在”固化为 a-0.10 线的第一真相。
2. 将这次 subagent 复核结果写成正式线文档，不再口头保留。
3. 重新定义 direct 100% 的 denominator：
   - `direct_covered` 行必须有真实 PicoUI public API。
   - `allowlisted` 行不能计入 direct public API 覆盖。
   - `runtime_host/internal_helper/lifecycle/show/backend_private_hook/native_action_private` 必须从 direct public denominator 中分层解释。
4. 对 `207` 个 allowlisted 行重新判定：
   - 哪些确实不应暴露；
   - 哪些是可选 direct-100 增强；
   - 哪些若用户坚持“PicoUI 对外 100%”，必须新增 public API。
5. 更新 `docs/ability/*`，让每个控件都显式说明 direct covered、policy allowlisted、direct-100 缺口。

## a-0.10 不做什么

1. 不把 `policy_complete_not_direct_100` 写成 direct 100%。
2. 不把 `allowlisted` 直接改名成 `covered`。
3. 不为 lifecycle/show/internal helper 强行暴露 public API。
4. 不把 backend 私有 hook、raw draw callback、native nameId action helper 当作 PicoUI portable API。
5. 不用 demo、截图、manual artifact 替代 public header、backend proof、unit/gate。

## 完成定义

1. `covered` 行引用的 PicoUI API 全部存在于 `picoui/include` public header。
2. `docs/ability/*` 不再显示不存在的 PicoUI public API 名。

1. PicoUI public API truth gate 已固化，`covered` 行不能再引用 `picoui/include` 中不存在的 API。
2. 当前不是 PicoUI 对外 public API direct 100%；事实为 `direct_public_covered_total=404`、`policy_allowlisted_total=207`、`direct_public_100_complete=false`。
3. `207` 个 allowlisted 行已分层：`policy_never_public=191`、`optional_public_extension=16`、`direct_100_required_if_user_demands=0`。
4. 因为没有 `direct_100_required_if_user_demands`，a-0.10 不新增 PicoUI public API。
5. `docs/ability/*` 已逐控件写明 direct public 100% 状态，不能再把 `missing_gap_total=0` 当成 direct 100%。
