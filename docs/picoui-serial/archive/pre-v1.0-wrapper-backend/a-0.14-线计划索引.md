## a-0.14 线定位

`a-0.14` 不是重新做一遍 `a-0.8` exhaustiveness，而是基于当前 worktree 再做一轮“代码 + 文档 + 复核”闭环，目标是继续逼近你要求的 user-facing 100%。

本线的硬要求：

1. 不能只看 `docs/ability`。
2. 必须以当前代码、public header、backend 映射、focused test、contract truth 为准。
3. 每修掉一个真实缺口，都要同步更新 `docs/ability`。
4. 每轮修复后都要重新启动只读 subagent 复核，而不是只靠主线程自证。

基于当前仓库代码、focused test 和 `docs/ability`，这轮代码面已把最后已知缺口 `background` 独立 public widget` 补上；下一步是继续同步 contract 三件套与独立复核证据，确认是否还有隐藏代码级缺口。
