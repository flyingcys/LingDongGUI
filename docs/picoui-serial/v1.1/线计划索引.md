# PicoUI v1.1 线计划索引

> 当前状态：`designing`

## 路线定义

`v1.1` 的目标不是继续维护 `v1.0-native` 的 `native/backend` 叠层，而是把 PicoUI 重构成真正独立、轻量、单心智的小型 GUI：

```text
picoui public API -> picoui widgets -> picoui core(hidden) -> arm2d/port
```

边界：

- 删除 `picoui/src/native/`
- 删除 `picoui/src/backend/`
- 删除 `picoui_app_*`
- `src/gui/ld*.c` 只作为算法参考，不进入默认 PicoUI 运行链
- 从 LingDongGUI 借来的代码必须改成 PicoUI 自己统一的函数风格
- PicoUI 保持“小型 GUI”定位，不走 LVGL 式大型框架路线
