# PicoUI v1.1 C2 垂直切片实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立 `window/label/button` 的第一条真实 `api -> widgets -> core -> arm2d/port` 垂直链，并把 `basic_widgets` 改造成 v1.1 样板入口。

**Architecture:** 本阶段只做最小闭环，不扩散到其他控件。`window` 提供根容器和 child tree，`label` 提供最小文本渲染，`button` 提供 pressed/click 行为和基础绘制，`basic_widgets` 只保留能证明新链通了的最小 UI。

**Tech Stack:** C11, CMake, SDL2, ARM-2D, PicoUI widgets/core, `rtk cmake`, `rtk ctest`, Python runtime checks.

struct picoui_window *picoui_window_create_root(struct picoui_screen *screen)
{

    if (screen == 0) {
        return 0;
    }
    root.widget.parent = 0;
    root.widget.first_child = 0;
    root.widget.next_sibling = 0;
    root.widget.visible = 1;
    root.widget.enabled = 1;
    return &root;
}
```

int picoui_button_set_pressed(struct picoui_button *button, int pressed)
{
    if (button == 0) {
        return -1;
    }
    if (button->pressed && !pressed && button->on_clicked != 0) {
        button->on_clicked(button, button->on_clicked_user_data);
    }
    button->pressed = pressed ? 1 : 0;
    button->widget.dirty = 1;
    return 0;
}

int picoui_button_get_pressed(const struct picoui_button *button)
{
    return (button == 0) ? 0 : button->pressed;
}
```
