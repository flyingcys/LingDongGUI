# C2 阶段记录

## C2-A `window` 根容器和 child tree 真相收口

- 目标：只为 `v1.1` 路线补最小 `window root + child tree` 真相，不引回 legacy backend/native tree。
- RED：`test_picoui_v1_1_window_tree` 链接失败，缺少 `picoui_window_create_root`、`picoui_label_create`、`picoui_widget_get_parent`、`picoui_widget_get_first_child`、`picoui_widget_get_next_sibling` 的 `v1.1` 实现符号。
- GREEN：新增 `widget_v1_1.c`、`window_v1_1.c`、`label_v1_1.c`，只挂到 `picoui_core_v1_1` / `picoui_widgets_v1_1`；`picoui_window_create_root()` 负责 root 建立与 screen 绑定，`picoui_label_create()` 负责 append child，tree query 已能返回 root/child/sibling 真相。
- 当前边界：本次只完成 `C2-A` 的 `window/tree` 最小闭环；`label render`、`button`、更完整 widget API 仍未进入本阶段完成口径。

## C2-B `label` 本地 text state 与最小 render

- 目标：只为 `v1.1` 路线补 `label` 本地 text authority 与最小 render pass，不引回 legacy backend readback 或真实绘制。
- RED：新增 `test_picoui_v1_1_label_render` 后首次编译失败，错误为 `struct picoui_widget` 缺少 `dirty` 字段，说明 `v1.1` 还没有可被 `timer_handler()` 消化的本地 render state。
- GREEN：在 `internal_v1_1.h` 为 `widget` 补最小 `text/dirty` 字段，`label_v1_1.c` 让 `picoui_label_set_text()` 写本地 authority 并置 dirty，`picoui_label_get_text()` 直接返回本地 state；新增 `core/render.c` 递归走 active screen root tree，只做清 dirty；`picoui_timer_handler()` 已改为调用该最小 render pass。
- 当前边界：本次只完成到 `label` 本地 `text/render` 最小闭环；未覆盖 `button/basic_widgets`，也未引入更完整 widget 属性或真实 backend 渲染。

## C2-C `button` pressed/click 语义与本地 authority

- 目标：只为 `v1.1` 路线补 `button` 的本地 `pressed/clicked` authority，不引回 legacy backend button action，也不扩到 `basic_widgets`。
- RED：新增 `test_picoui_v1_1_button_state` 后先确认过两层失败：一是目标未重配进 build graph 前 `No rule to make target 'test_picoui_v1_1_button_state'`；二是重配后链接失败，缺少 `picoui_button_create`、`picoui_button_set_on_clicked`、`picoui_button_set_pressed`、`picoui_button_get_pressed` 的 `v1.1` 实现符号。
- GREEN：新增 `button_v1_1.c`，只挂到 `picoui_widgets_v1_1`；`picoui_button_create()` 负责本地创建与 child append，`picoui_button_set_on_clicked()` 只登记本地 callback，`picoui_button_set_pressed()` 在 `pressed=1 -> 0` 时触发一次 clicked callback 并置 dirty，`picoui_button_get_pressed()` 直接回读本地 state。
- 当前边界：本次只完成 `button` 本地 authority 和 `pressed/click` 最小语义；未接入真实 input dispatch、真实 backend 绘制，也未宣称 `basic_widgets/C2` 整体完成。
