# PicoUI v1.0 Native 线计划索引

> 当前状态：路线建立中  
> 目标版本：首个 native-only release 为 `v1.0.1`

## 路线定义

从 `v1.0` 开始，PicoUI 不再继续扩展 `LingDongGUI backend wrapper` 路线。新方向是：

```text
PicoUI public API -> PicoUI native runtime/widgets -> ARM-2D -> PicoUI port/display
```

边界：

- 删除 PicoUI 对 `picoui/src/backend/ldgui/` 的 runtime 依赖。
- v1.0+ public 开发模式对齐 LVGL：`picoui_init()`、display/input 注册、active screen、`picoui_timer_handler()` 主循环。
- `picoui_app_*` 不再是 v1.0+ 主路径；是否保留为 compatibility wrapper 由 P0 冻结决策。
- 保留仓库 `src/gui/ld*.c` 作为迁移参考和对照 oracle。
- 不删除 LingDongGUI 主体代码。
- 不把旧 backend mapping gate 当成 native 完成证据。

## 阶段

1. `P0`：基线冻结，生成 public API、demo、contract、ldgui dependency 快照。
2. `P1`：native 垂直切片，跑通 `init/display/indev/screen/window/label/button/timer_handler`，并把 `picoui/demo/basic_widgets/main.c` 改成 LVGL-like main 样板。
3. `P2`：core widget、layout、theme native 化。
4. `P3`：基础控件迁移。
5. `P4`：扩展控件迁移。
6. `P5`：resource/font/image/text 完整化。
7. `P6`：demo、SDL port、artifact、board port 准备，并按 `basic_widgets` 样板批量迁移其余 demo main。
8. `P7`：删除 PicoUI 对 ldgui backend 的默认构建依赖。
9. `P8`：`v1.0.1` release gate。
