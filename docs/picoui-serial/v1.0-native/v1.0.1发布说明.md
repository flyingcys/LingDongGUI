## 本版结论

`v1.0.1` 是 PicoUI 首个 native-only release：

- 默认构建路径使用 `PICOUI_RUNTIME=native_arm2d`
- 默认 release gate 要求 `PICOUI_ENABLE_LEGACY_LDGUI=OFF`
- `picoui` 默认 target 不再依赖 `picoui/src/backend/ldgui/*`
- `picoui_app_*` 仍保留在 public header，但只作为 compatibility wrapper，不再是 `v1.0+` 主路径

同时必须明确：

- 仓库仍保留 `src/gui/ld*.c` 和 legacy `ldgui` 相关代码，作为迁移参考与 oracle
- “保留参考代码” 不等于 “PicoUI runtime 仍依赖 LingDongGUI backend”

## 当前交付面

当前 `v1.0.1` 发布面包括：

- native runtime / display / indev / screen / root window 主路径
- `basic widgets` 与 `extended widgets` 的 native-focused contract
- `resource / font / image / canvas / qrcode / animation` native renderer 路径
- SDL native port
- 全量 `v1.0+ demo main` 的 LVGL-like 主路径迁移
- native release matrix、migration ledger、demo main style contract、no-ldgui runtime dependency contract

当前 `native artifact` 结果分层如下：

- `visible`: `21`
- `runtime_only`: `7`
- `failures`: `0`

这表示：

- 当前 broad native artifact gate 已经全绿
- 但仍有 `7` 个 demo 只收到了 runtime-ready 证据，没有被写成 visible parity 通过

## 升级与使用说明

### 新主路径

`v1.0+` quick start 应使用：

1. `picoui_init()`
2. `picoui_sdl_hal_init(width, height)` 或自定义 display/indev 注册
3. `picoui_screen_active()`
4. `picoui_window_create_root()`
5. `picoui_screen_load()`
6. 周期调用 `picoui_timer_handler()`
7. `picoui_deinit()`

参考文档：

- [picoui/docs/quick_start.md](/Users/cys/embedded/LingDongGUI/picoui/docs/quick_start.md)
- [picoui/docs/porting_rules.md](/Users/cys/embedded/LingDongGUI/picoui/docs/porting_rules.md)
- [picoui/docs/api_overview.md](/Users/cys/embedded/LingDongGUI/picoui/docs/api_overview.md)

### compatibility wrapper 边界

以下 API 当前仍保留，但不是 `v1.0+` 推荐主路径：

- `picoui_app_create()`
- `picoui_app_run()`
- `picoui_app_destroy()`
- `picoui_app_run_background()`

现阶段它们只应用于：

- 旧 demo / 旧测试的兼容过渡
- 历史 wrapper 路线对照

### 构建开关

`v1.0.1` release 构建应使用：

```bash
rtk cmake -S . -B build-native-release \
  -DPICOUI_RUNTIME=native_arm2d \
  -DPICOUI_ENABLE_LEGACY_LDGUI=OFF \
  -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
```

## 已知边界

- 当前 native release 证明的是 contract/runtime/artifact gate 已闭合，不等于所有 demo 已达到人工 visible parity。
- `runtime_only` demo 必须按 manifest 中的分层说明理解，不能上抬成 visible 通过。
- 当前 release 允许仓库继续保留 LingDongGUI 参考代码；禁止把这点误写成 “native-only 不成立”。
- 旧 `backend mapping` gate 不再是 `v1.0.1` native 完成证据。
