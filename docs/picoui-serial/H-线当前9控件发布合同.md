# PicoUI H线当前 9 控件发布合同

## 目的

本文是 `H4` 的当前 `9` 控件 release contract 真相源，只回答当前 first release 对每个已覆盖控件实际承诺什么、不承诺什么。

边界约束：

- 只覆盖当前 `9` 个已覆盖控件：`window`、`label`、`button`、`checkbox`、`switch`、`slider`、`text`、`image`、`list`。
- 不扩控件，不把 `H线` 之后的新控件候选写回当前发布面。
- `supported APIs` 只写当前 public API 和已被当前合同承认的能力子集。
- `evidence layers` 必须分层表达 `unit / contract / mapping / visible / manual_artifact`，不得把自动 gate 与人工验收混写。
- `first-release wording` 只允许诚实表述，不得把 “有 backend mapping” 写成 “完整镜像 LingDongGUI”。

## 证据层说明

- `unit`：单元级行为或边界测试存在。
- `contract`：合同矩阵/release matrix 已记录当前状态。
- `mapping`：真实 backend 映射已存在，落到真实 `ld*` 或真实 `ldBase` 能力。
- `visible`：automatic visible gate 有当前控件样本或由当前控件参与的可见样本。
- `manual_artifact`：当前只允许写 `artifact_entry_exists` 与 `manual_review_required` 语义；本文不宣称人工验收已通过。

当前 `9` 个控件在 H2 release matrix 中都属于：

- `widget_status = wrapped`
- `widget_release_judgement = internal_v0_1_known_limitation`

这表示它们属于当前 `internal v0.1` 讨论范围，但发布说明仍必须配套 known limitations，不表示控件已经达到 “完整支持”。

## `window`

### supported APIs

- `picoui_window_create()`
- `picoui_window_create_with_props()`
- layout 子集：flex、grid、padding、gap、align
- style 子集：background color
- 通用 widget 状态：visible、enabled
- theme token 子集

### backed by ld* entries

- `ldWindow`
- `ldWindowSetColor`
- `ldWindowSetLayout`
- `ldWindowSetFlexFlow`
- `ldWindowSetFlexAlign`
- `ldWindowSetFlexTrackAlign`
- `ldWindowSetPadding`
- `ldWindowSetFlexGap`
- `ldWindowSetGridColumns`
- `ldWindowSetGridDscArray`
- `ldWindowSetGridAlign`
- `ldWindowSetGridGap`
- `ldWindowSetGridPadding`

### evidence layers

- `unit`: present
- `contract`: present
- `mapping`: present
- `visible`: present
- `manual_artifact`: `artifact_entry_exists = false`, `manual_review_required = true`

### known limitations

- 不承诺 `ldWindow` 全部内部布局选项。
- 不承诺 window background image。
- 不承诺 `PaddingGroup` 等更底层分组 padding 语义。

### first-release wording

第一版只发布 `window` 的容器与布局子集合同：支持真实 `ldWindow` backend 承接的 flex/grid/padding/gap/align 与背景色，不宣称等价覆盖 `ldWindow` 全 API。

## `image`

### supported APIs

- `picoui_image_create()`
- `picoui_image_create_with_props()`
- `picoui_image_set_source()`
- source 绑定/清空
- 通用 base 能力子集：pos、size、visible、flex、grid、ignore_layout

### backed by ld* entries

- `ldImage`
- `ldBase` 通用布局/可见性能力
- `ptImgTile / ptMaskTile` 真实 backend 同步路径

### evidence layers

- `unit`: present
- `contract`: present
- `mapping`: present
- `visible`: present
- `manual_artifact`: `artifact_entry_exists = false`, `manual_review_required = true`

### known limitations

- `theme`: `reject`
- `style_class`: `incomplete_contract`，当前只承认 metadata-only 合同，不承诺真实 `ldImage` 消费链
- `user_data`: `incomplete_contract`，当前只承认 metadata-only 合同，不承诺 backend 语义
- `bg_color / text_color / border_color / radius`: `reject`
- `padding`: `deferred`
- `enabled`: `reject`
- 不承诺完整资源加载系统。
- 不承诺 mask color。

### first-release wording

第一版只把 `image` 发布为基础图片 source 绑定与布局显示控件：支持真实 `ldImage` source/backend tile 映射以及基础 visible/layout 行为。必须显式写明 `theme`、`enabled`、颜色/边框/radius style 为 `reject`，`style_class/user_data` 只是 metadata-only 合同，`padding` 仍是 `deferred`；不得把这些限制模糊成“部分支持”。

## `list`

### supported APIs

- `picoui_list_create()`
- `picoui_list_create_with_props()`
- `picoui_list_add_item()`
- `picoui_list_set_selected_index()`
- `picoui_list_get_selected_index()`
- `picoui_list_set_on_selected()`
- theme main 子集
- 通用 widget 状态：visible、enabled

### backed by ld* entries

- `ldList`
- `ldListSetText`
- `ldListSetSelectItem`
- 真实 list visible / selection backend 映射路径

### evidence layers

- `unit`: present
- `contract`: present
- `mapping`: present
- `visible`: present
- `manual_artifact`: `artifact_entry_exists = false`, `manual_review_required = true`

### known limitations

- `item marker`: `reject`，不得把 item id 或 marker 写成真实 backend widget support
- `style_class`: `incomplete_contract`，当前只承认 metadata-only 合同
- `widget-level user_data`: `incomplete_contract`，当前只承认 metadata-only 合同
- `on_selected(..., user_data)` callback cookie 与 widget-level `user_data` 明确分离：前者是 callback cookie support，后者不是 backend 语义 support
- 不承诺 item child widget。
- 不承诺 item height。
- 不承诺 text align。
- 不承诺 padding / margin。

### first-release wording

第一版只把 `list` 发布为基础列表控件：支持 add item、selected index、真实 `ldList` 文本/选择映射以及 `on_selected(..., user_data)` callback cookie。必须显式写明 item marker 是 `reject`，`style_class` 与 widget-level `user_data` 是 metadata-only `incomplete_contract`，且 callback cookie 不等于 widget-level `user_data` support。

## 当前发布面统一结论

- 当前 `9` 控件都可以进入 `internal v0.1` 发布讨论范围。
- 这 `9` 个控件都不是 “完整镜像 LingDongGUI 对应控件”。
- `image` 与 `list` 是当前 first release 里风险最高的两个已覆盖控件，限制必须在 release notes 与 known limitations 中原样保留。
- `visible`、`mapping`、`manual_artifact` 是不同证据层：当前只能说自动证据已存在，不能说人工验收已完成。
