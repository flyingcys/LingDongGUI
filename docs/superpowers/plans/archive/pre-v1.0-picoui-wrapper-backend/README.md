# PicoUI pre-v1.0 plan 归档

> 归档日期：2026-06-05  
> 当前路线入口：`docs/picoui-serial/v1.0-native/线计划索引.md`

本目录保存 PicoUI 在 `v1.0` 前的 implementation plans。旧计划默认围绕 `LingDongGUI backend wrapper`、旧 mapping gate、旧 visible/runtime gate 推进。

当前 `v1.0+` 开发不得直接按这些计划继续执行。若需要迁移能力，只能把旧计划作为能力清单和测试 oracle 输入，再按 native runtime 新计划重写。
