# TinyUI v2.2 到 v2.3 迁移指南

## 迁移性质

v2.3 是破坏式 canonical API 收口，**不承诺 v2.2 legacy ABI**。迁移目标不是保留两套入口，而是把用户代码统一到轻量、LVGL 风格的 TinyUI public API。

**禁止继续使用 `v22_demo_bridge`。** 仓内临时迁移桥（`internal/v22_demo_bridge.h` / `src/compat/v22_demo_bridge.c` 及对应私有接线）已删除，不得在用户工程、demo、测试或文档中重新引入。任何 `tinyui_app_*`、`tinyui_widget_*`、错拼控件名等旧符号都不再作为可依赖入口。

port 初始化、flush、tick、SDL/MCU 细节不在本指南处理范围；见 [延期 Port 工作](./deferred-port-work.md)。本指南不声称 v2.3 全部完成，也不声称 port 达到 L6 或生产可用。

统一入口头：`#include <tinyui.h>`。仓外消费方式见第 11 章。

---

## 1. `app_create/app_run` → `init + screen + process`

v2.2 以 `tinyui_app *` 持有生命周期，并提供阻塞式 `tinyui_app_run()`。v2.3 改为单实例 runtime：`tinyui_init` / `tinyui_deinit`，用户持有主循环并反复调用 `tinyui_process`。

| v2.2 / legacy | v2.3 |
| --- | --- |
| `tinyui_app_create()` | `tinyui_init()` |
| `tinyui_app_destroy(app)` | `tinyui_deinit()` |
| `tinyui_app_run(app, window)` | `tinyui_screen_load(...)` + 循环 `tinyui_process(&next_ms)` |
| `tinyui_app_run_background(app, bg)` | `tinyui_background_create()` + `tinyui_screen_load(bg, ...)` |
| `tinyui_app_set_window(app, window)` | `tinyui_screen_load(window, NONE, 0)` |
| `tinyui_app_switch_window(...)` | `tinyui_screen_load(window, transition, ms)` |
| `tinyui_timer_handler()` | `tinyui_process(&next_ms)` |

v2.3 **不提供**新的阻塞式 `run()`。sleep、RTOS 等待、输入泵送由用户/port 持有。

**Before（v2.2）：**

```c
tinyui_app *app = tinyui_app_create();
tinyui_window *win = tinyui_window_create(app, "main");
/* ... 创建控件 ... */
tinyui_app_run(app, win);   /* 阻塞，内部驱动帧循环 */
tinyui_app_destroy(app);
```

**After（v2.3）：**

```c
#include <tinyui.h>

int app_main(void)
{
    tinyui_result_t result;
    tinyui_obj_t *screen;
    uint32_t next_ms = 0;
    int running = 1;

    result = tinyui_init();
    if (result != TINYUI_OK) {
        return 1;
    }

    screen = tinyui_screen_create();
    if (screen == NULL) {
        tinyui_deinit();
        return 1;
    }

    /* 在 screen 下创建控件，见后续章节 */

    result = tinyui_screen_load(screen, TINYUI_SCREEN_TRANSITION_NONE, 0);
    if (result != TINYUI_OK) {
        tinyui_obj_delete(screen);
        tinyui_deinit();
        return 1;
    }

    while (running) {
        result = tinyui_process(&next_ms);
        if (result != TINYUI_OK) {
            break;
        }
        /* 集成层：按 next_ms 休眠 / 推进时钟 / 泵送输入 */
        (void)next_ms;
    }

    tinyui_obj_delete(screen);
    tinyui_deinit();
    return 0;
}
```

## 2. typed widget 指针与强转 → `tinyui_obj_t *`

所有公开控件统一返回 `tinyui_obj_t *`，parent 也统一为 `tinyui_obj_t *`。用户代码不得再依赖 typed wrapper 布局，也不得把 `tinyui_obj_t *` 强转为 `tinyui_window *` / `tinyui_button *` 等旧类型。

**Before：**

```c
tinyui_window *win = tinyui_window_create(app, "main");
tinyui_label  *lab = tinyui_label_create(win, "title");
tinyui_button *btn = (tinyui_button *)tinyui_widget_find_by_name_id(win, "ok");
```

**After：**

```c
tinyui_obj_t *screen = tinyui_screen_create();
tinyui_obj_t *lab    = tinyui_label_create(screen);
tinyui_obj_t *btn    = tinyui_button_create(screen);

/* 按 16 位 ID 查找（创建时通过 props 设置，见第 3 章） */
uint16_t id = 0;
(void)tinyui_obj_get_id(btn, &id);
tinyui_obj_t *found = tinyui_obj_find_by_id(screen, id);
(void)found;
```

删除以下使用方式：

- `tinyui_obj_t *` 强转为 `tinyui_window *` / 其他 typed 指针。
- creator 接收 public `tinyui_app *`。
- 用户代码依赖 typed wrapper 的成员布局。

---

## 3. `create(app/window, id)` → `create(parent)` / props

v2.2 creator 常把 `app`/`window` 与字符串 `id` 塞进参数列表。v2.3 creator 只接收 `parent`；可选字段通过 `*_create_with_props` 与 **presence mask** 设置。`0/-1/NULL` 不再隐式表示“字段未设置”。

ID 为 16 位整数，在创建时经 props 设置，创建后不可修改；同一 root 内显式 ID 必须唯一。字符串 `id` / `style_class` 已删除。

| v2.2 | v2.3 |
| --- | --- |
| 字符串 `id` / `style_class` | `uint16_t id`；style class 删除 |
| `tinyui_widget_get_name_id()` | `tinyui_obj_get_id()` |
| `tinyui_widget_find_by_name_id()` | `tinyui_obj_find_by_id()` |

**Before：**

```c
tinyui_button *btn = tinyui_button_create(app, win, "ok_btn");
tinyui_label_set_text(lab, "Hello");
```

**After：**

```c
tinyui_obj_t *screen = tinyui_screen_create();
tinyui_obj_t *lab    = tinyui_label_create(screen);
tinyui_obj_t *btn;

tinyui_button_props_t props = {0};
props.fields = TINYUI_BUTTON_FIELD_ID | TINYUI_BUTTON_FIELD_TEXT;
props.id     = 1001;
props.text   = "OK";

btn = tinyui_button_create_with_props(screen, &props);
if (btn == NULL) {
    /* 处理失败 */
}

(void)tinyui_label_set_text(lab, "Hello");
```

无 props 时也可先 `tinyui_button_create(parent)`，再调用控件专用 setter。

## 4. widget/window 通用 setter → `tinyui_obj_set_*`

跨控件通用几何/外观属性统一走 `tinyui_obj_set_*`。所有 setter 返回 `tinyui_result_t`；不支持的控件/属性组合返回 `TINYUI_ERROR_NOT_SUPPORTED`，不再只写 wrapper 镜像。

位置等 getter 改为 `result + out parameter`，不再用合法值 `-1` 表示错误。文本 setter 从“保存调用者指针”改为复制字符串；调用者可在 setter 返回后释放原缓冲区。

| v2.2 | v2.3 |
| --- | --- |
| `tinyui_widget_set_pos()` | `tinyui_obj_set_pos()` |
| `tinyui_widget_set_size()` | `tinyui_obj_set_size()` |
| `tinyui_widget_set_text()` | `tinyui_obj_set_text()` |
| `tinyui_widget_set_bg_color()` | `tinyui_obj_set_bg_color()` |
| `tinyui_widget_set_text_color()` | `tinyui_obj_set_text_color()` |
| `tinyui_widget_set_border_color()` | `tinyui_obj_set_border_color()` |
| `tinyui_widget_set_radius()` | `tinyui_obj_set_radius()` |
| `tinyui_widget_set_padding()` | `tinyui_obj_set_padding()` |
| `tinyui_widget_set_visible()` | `tinyui_obj_set_visible()` |
| `tinyui_widget_set_enabled()` | `tinyui_obj_set_enabled()` |
| `tinyui_widget_destroy()` | `tinyui_obj_delete()` |

**Before：**

```c
tinyui_widget_set_pos((tinyui_widget *)lab, 10, 20);
tinyui_widget_set_size((tinyui_widget *)lab, 120, 32);
tinyui_widget_set_text((tinyui_widget *)lab, "Title");
tinyui_widget_set_bg_color((tinyui_widget *)lab, 0x202020);
tinyui_widget_set_visible((tinyui_widget *)btn, 1);
tinyui_widget_destroy((tinyui_widget *)lab);
```

**After：**

```c
(void)tinyui_obj_set_pos(lab, 10, 20);
(void)tinyui_obj_set_size(lab, 120, 32);
(void)tinyui_obj_set_text(lab, "Title");
(void)tinyui_obj_set_bg_color(lab, 0x202020u);
(void)tinyui_obj_set_visible(btn, 1);

/* 删除对象（子树随 parent 释放；也可单独 delete） */
(void)tinyui_obj_delete(lab);
```

控件特有属性仍用 `tinyui_<widget>_set_*`（例如 `tinyui_button_set_text`）。

## 5. 旧 callback → `tinyui_event_t` + handle remove

控件专用 callback 迁移到统一事件 API。callback 来自固定容量池；删除时使用 generation handle，不能保存固定池索引。

v2.3 事件同步直达 target：

- 不冒泡、不 capture、不排队。
- 不再公开 `SIGNAL_*` 或 `tinyui_native_signal`。

**Before：**

```c
static void on_ok(tinyui_button *btn, void *user)
{
    (void)btn;
    (void)user;
    /* 处理点击 */
}

tinyui_button_set_on_click(btn, on_ok, NULL);
/* 或 SIGNAL_* / native signal 绑定 */
```

**After：**

```c
static void on_button_event(const tinyui_event_t *event)
{
    if (event == NULL) {
        return;
    }
    if (event->code == TINYUI_EVENT_CLICKED) {
        (void)event->target;
        (void)event->user_data;
    }
}

tinyui_event_handle_t handle = 0;
tinyui_result_t result = tinyui_obj_add_event_cb(
    btn,
    TINYUI_EVENT_MASK(TINYUI_EVENT_CLICKED),
    on_button_event,
    NULL,
    &handle);
if (result != TINYUI_OK) {
    /* 池满或参数错误 */
}

/* 需要移除时使用同一 handle，不要缓存槽位下标 */
(void)tinyui_obj_remove_event_cb(btn, handle);
```

部分控件仍提供窄封装（如 `tinyui_button_set_on_clicked`），语义上转发到同一事件池。

Focus / Key 相关迁移提示：

| v2.2 | v2.3 |
| --- | --- |
| `tinyui_focus_reset(app)` | `tinyui_focus_clear()` |
| `tinyui_focus_navigate(app, native_dir)` | `tinyui_focus_move(tinyui_focus_direction_t)` |
| key state round-trip | UI 线程 `tinyui_input_send_key(key, pressed)` |

`tinyui_native_nav_dir` 不再公开。

## 6. app timer → 固定池 `tinyui_timer_*`

timer 不再挂在 `tinyui_app *` 上，也不再逐帧创建 snapshot heap。v2.3 使用固定容量池（默认 `TINYUI_TIMER_CAPACITY`）。

| v2.2 | v2.3 |
| --- | --- |
| `tinyui_app_timer_create(app)` | `tinyui_timer_create(interval, repeat, cb, data)` |
| `tinyui_app_timer_start()` | `tinyui_timer_start()` |
| `tinyui_app_timer_stop()` | `tinyui_timer_stop()` |
| `tinyui_app_timer_destroy()` | `tinyui_timer_delete()` |

**Before：**

```c
tinyui_timer *t = tinyui_app_timer_create(app);
tinyui_app_timer_set_interval(t, 100);
tinyui_app_timer_set_cb(t, on_tick, NULL);
tinyui_app_timer_start(t);
/* ... */
tinyui_app_timer_destroy(t);
```

**After：**

```c
static void on_tick(tinyui_timer_t *timer, void *user_data)
{
    (void)timer;
    (void)user_data;
    /* 周期性工作 */
}

tinyui_timer_t *t = tinyui_timer_create(100, true, on_tick, NULL);
if (t == NULL) {
    /* 池满 */
}
(void)tinyui_timer_start(t);

/* 需要时：tinyui_timer_stop(t); tinyui_timer_set_interval(t, 200); */
tinyui_timer_delete(t);
```

主循环仍由 `tinyui_process(&next_ms)` 推进；`next_ms` 反映最近 timer/动画 deadline。

## 7. 旧 theme/style → descriptor apply

删除动态 `tinyui_theme_create/destroy()`、字符串 `style_class` 以及“保存 style 指针做级联”的模型。

Theme 使用静态/用户持有的值表：`tinyui_theme_set` + `tinyui_theme_apply`。临时 style 使用值 descriptor 立即应用；TinyUI **不保存** style 指针，不做 selector 或级联。调用返回后可销毁 descriptor。

**Before：**

```c
tinyui_theme *theme = tinyui_theme_create();
tinyui_theme_set_color(theme, "bg", 0x101010);
tinyui_app_set_theme(app, theme);
tinyui_widget_set_style_class((tinyui_widget *)btn, "primary");
tinyui_theme_apply_to_widget(theme, (tinyui_widget *)btn);
tinyui_theme_destroy(theme);
```

**After：**

```c
static const tinyui_theme_t theme = {
    .colors = {
        [TINYUI_COLOR_TEXT_PRIMARY] = 0xEEEEEE,
        [TINYUI_COLOR_BG]           = 0x101010,
        [TINYUI_COLOR_PANEL]        = 0x202020,
        [TINYUI_COLOR_BORDER]       = 0x404040,
        [TINYUI_COLOR_ACCENT]       = 0x3A7AFE,
        [TINYUI_COLOR_DISABLED]     = 0x666666,
    },
    .metrics = {
        [TINYUI_METRIC_PADDING]        = 8,
        [TINYUI_METRIC_RADIUS]         = 4,
        [TINYUI_METRIC_BORDER_WIDTH]   = 1,
        [TINYUI_METRIC_CONTROL_HEIGHT] = 32,
    },
};

(void)tinyui_theme_set(&theme);
(void)tinyui_theme_apply(screen);

/* 单次 style 值应用（返回后 style 可丢弃） */
tinyui_style_t style = {0};
style.fields     = TINYUI_STYLE_BG_COLOR | TINYUI_STYLE_RADIUS;
style.bg_color   = 0x303030u;
style.radius     = 6;
(void)tinyui_obj_apply_style(btn,
                             TINYUI_PART_MAIN,
                             TINYUI_STATE_DEFAULT,
                             &style);
```

## 8. grid 负数魔数/sentinel → typed track + count

flex/grid container 参数统一为 `tinyui_obj_t *`。grid 从裸负数 magic integer / END sentinel 改为 typed track + 显式 count。最大 track 数为 `TINYUI_GRID_MAX_TRACKS`（16）。

**Before：**

```c
/* 伪例：负数表示 fr/content，-1 作 END sentinel */
int columns[] = { 80, -1 /* 1fr */, -2 /* content */, -1 /* END */ };
tinyui_grid_set_columns(container, columns);
```

**After：**

```c
static const tinyui_grid_track_t columns[] = {
    { TINYUI_GRID_UNIT_PX, 80 },
    { TINYUI_GRID_UNIT_FR, 1 },
    { TINYUI_GRID_UNIT_CONTENT, 0 },
};

(void)tinyui_grid_set_columns(container, columns, 3);

static const tinyui_grid_track_t rows[] = {
    { TINYUI_GRID_UNIT_CONTENT, 0 },
    { TINYUI_GRID_UNIT_FR, 1 },
};
(void)tinyui_grid_set_rows(container, rows, 2);
(void)tinyui_grid_set_gap(container, 8, 8);

/* 子项占位 */
(void)tinyui_obj_set_grid_cell(child,
                               0, 0, 1, 1,
                               TINYUI_ALIGN_STRETCH,
                               TINYUI_ALIGN_CENTER);
```

flex 同样只接收 `tinyui_obj_t *`：

```c
(void)tinyui_flex_set_flow(container, TINYUI_FLEX_FLOW_ROW);
(void)tinyui_flex_set_gap(container, 8, 0);
```

## 9. image/font 旧句柄 → caller-owned descriptor/deinit

图片与字体改为**调用者持有**的轻量值 descriptor。绑定到对象期间 source/font 必须保持有效；解绑或对象删除后由调用者 `*_deinit`。

支持：

- 图片：RGB565 memory、builtin、VRES；可选 A8 mask。
- 字体：可直接映射的 builtin 与 VRES value。

ARGB8888 source 在直接 backend 适配闭环前返回 `NOT_SUPPORTED`。删除 family 字符串 fallback 和新的 glyph/provider 协议。

**Before：**

```c
tinyui_image *img = tinyui_image_load_file("note.png");
tinyui_image_widget_set_image(widget, img);
tinyui_image_destroy(img);   /* 旧句柄语义因实现而异 */

tinyui_font *font = tinyui_font_open("sans", 16);
tinyui_label_set_font(lab, font);
tinyui_font_close(font);
```

**After：**

```c
static tinyui_image_source_t s_note_icon;
static tinyui_font_t         s_font;

void page_bind_resources(tinyui_obj_t *image, tinyui_obj_t *label)
{
    if (tinyui_image_source_from_builtin(TINYUI_BUILTIN_IMAGE_NOTE,
                                         &s_note_icon) != TINYUI_OK) {
        return;
    }
    (void)tinyui_image_set_source(image, &s_note_icon);

    if (tinyui_font_from_builtin(TINYUI_FONT_6X8, &s_font) != TINYUI_OK) {
        return;
    }
    (void)tinyui_label_set_font(label, &s_font);
}

void page_unbind_resources(void)
{
    /* 仅在对象已解绑/删除后调用 */
    tinyui_font_deinit(&s_font);
    tinyui_image_source_deinit(&s_note_icon);
}
```

未绑定到对象前即可释放 descriptor。长期显示的资源应放在静态存储、页面状态或应用状态中。

## 10. `tabel` / `scroll_selecter` / `q_r_code` / `set_press` → canonical 拼写

旧错拼与重复语义名称**不进入** `tinyui.h`，也不承诺链接兼容符号。

| 删除名称 | canonical 名称 |
| --- | --- |
| `tinyui_tabel_*` / `tinyui_tabel_show_keyboard` | `tinyui_table_*` / `tinyui_table_show_keyboard` |
| `tinyui_scroll_selecter_*` | `tinyui_scroll_selector_*` |
| `tinyui_q_r_code_*` | `tinyui_qrcode_*` |
| `set_press` / 重复的 `set_pressed` | 每项只保留一个 `set_pressed` 语义 |
| `set_select_item` / `set_selected_index` | `set_selected_index` |
| `set_msg` / `set_message` | `set_message` |

**Before：**

```c
tinyui_tabel *table = tinyui_tabel_create(win, "t");
tinyui_scroll_selecter *ss = tinyui_scroll_selecter_create(win, "s");
tinyui_q_r_code *qr = tinyui_q_r_code_create(win, "q");
tinyui_button_set_press(btn, 1);
```

**After：**

```c
tinyui_obj_t *table = tinyui_table_create(screen);
tinyui_obj_t *ss    = tinyui_scroll_selector_create(screen);
tinyui_obj_t *qr    = tinyui_qrcode_create(screen);

(void)tinyui_button_set_pressed(btn, 1);
(void)tinyui_table_show_keyboard(table, 1);
```

迁移后应用源码中上述旧拼写必须为零命中（见文末验收）。

## 11. 源码 include / `add_subdirectory` → `find_package(TinyUI CONFIG REQUIRED)` + `TinyUI::tinyui`

普通用户工程不得再：

- `add_subdirectory(tinyui)` 或把 `tinyui/src` 编进业务目标；
- 直接把 LingDongGUI / Arm-2D 私有 include 加到业务目标；
- 包含 `core/native.h`、`internal/*`、LingDongGUI 头、Arm-2D 头。

安装后的唯一普通用户 target 为 `TinyUI::tinyui`。统一包含 `<tinyui.h>`。

**Before：**

```cmake
add_subdirectory(${LINGDONG_ROOT}/tinyui tinyui_build)
target_include_directories(your_app PRIVATE
    ${LINGDONG_ROOT}/tinyui/include
    ${LINGDONG_ROOT}/tinyui/src
    ${LINGDONG_ROOT}//* private paths */)
target_link_libraries(your_app PRIVATE tinyui_core longdonggui)
```

```c
#include "tinyui/internal/app.h"
#include "widgets/button.h"
```

**After：**

```cmake
find_package(TinyUI 2.3 CONFIG REQUIRED)
target_link_libraries(your_app PRIVATE TinyUI::tinyui)
```

```c
#include <tinyui.h>
```

平台集成头（display / indev / tick 等）仍须在集成层**显式** include，且不由 `tinyui.h` 聚合。确有高级互操作需求时显式包含 native 扩展头；该路径不保证 TinyUI getter 与直接 native 修改同步。

## 12. 不兼容说明：v2.3 不承诺 v2.2 ABI；port 生产问题仍延期

1. **ABI / API**
   v2.3 不承诺与 v2.2 的二进制或符号兼容。旧符号、错拼名、`tinyui_app_*` / `tinyui_widget_*` 等不得依赖链接兼容。重新编译并改写调用方是唯一支持路径。

2. **迁移桥已删除**
   **禁止继续使用 `v22_demo_bridge`。** 不得保留、改名或重新启用任何形式的 v2.2 demo 迁移桥。文档与工程中不要写“请启用某种 INTERNAL V22 DEMO BRIDGE”之类指引。

3. **port 与 L6**
   framebuffer / stride / PFB、flush / DMA / fence、平台时钟、SDL event pump、MCU toolchain / RTOS / ISR / cache、真机验证等仍见 [延期 Port 工作](./deferred-port-work.md)。
   M4 的 SDL consumer / demo **只是测试宿主证据**，不是 L6，也不是生产可用证明。v2.3 核心/API 收口关闭后，port 生产问题仍延期。

4. **本指南边界**
   本文件只覆盖用户侧 canonical API 迁移。不声称 v2.3 全部里程碑已完成，不声称 port L6 完成。

## 迁移验收

每个迁移后的应用必须满足：

```sh
rtk rg -n 'tinyui_app_|tinyui_widget_|tinyui_native_|SIGNAL_|arm_2d_|v22_demo_bridge|#include .*internal|tinyui_tabel_|tinyui_scroll_selecter_|tinyui_q_r_code_|set_press' app_source
```

预期：除本迁移说明中的 before 对照、或显式 native 扩展文件外，零匹配。

应用还必须只通过安装后的 TinyUI target 编译，不添加 `tinyui/src`、LingDongGUI 或 Arm-2D private include path。
