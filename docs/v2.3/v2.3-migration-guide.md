# TinyUI v2.2 到 v2.3 迁移指南

## 迁移性质

v2.3 是破坏式 canonical API 收口，不承诺 v2.2 legacy ABI。迁移目标不是保留两套入口，而是把用户代码统一到轻量、LVGL 风格的 TinyUI API。

port 初始化、flush、tick、SDL/MCU 细节不在本指南处理范围。

## 生命周期

| v2.2/legacy | v2.3 |
| --- | --- |
| `tinyui_app_create()` | `tinyui_init()` |
| `tinyui_app_destroy(app)` | `tinyui_deinit()` |
| `tinyui_app_run(app, window)` | `tinyui_screen_load(root, NONE, 0)` + 用户循环调用 `tinyui_process(&next_ms)` |
| `tinyui_app_run_background(app, bg)` | `tinyui_background_create()` + `tinyui_screen_load(bg, NONE, 0)` |
| `tinyui_app_set_window(app, window)` | `tinyui_screen_load(window, NONE, 0)` |
| `tinyui_app_switch_window(app, window, mode, ms)` | `tinyui_screen_load(window, transition, ms)` |
| `tinyui_app_switch_background(...)` | `tinyui_screen_load(background, transition, ms)` |
| `tinyui_timer_handler()` | `tinyui_process(&next_ms)` |

v2.3 不提供新的阻塞式 `run()`。主循环、sleep 和 RTOS 等待由用户/port 持有。

## 对象与 creator

所有公开控件统一返回 `tinyui_obj_t *`，parent 也统一为 `tinyui_obj_t *`。

```c
tinyui_obj_t *screen = tinyui_screen_create();
tinyui_obj_t *label = tinyui_label_create(screen);
tinyui_obj_t *button = tinyui_button_create(screen);
```

删除以下使用方式：

- 把 `tinyui_obj_t *` 强转为 `tinyui_window *`。
- creator 接收 public `tinyui_app *`。
- 用户代码依赖 typed wrapper 布局。

props creator 统一使用 presence mask；`0/-1/NULL` 不再隐式表示“字段未设置”。

## ID

v2.3 ID 为 16 位整数，在创建时通过 props 设置，创建后不可修改。同一 root 内显式 ID 必须唯一。

| v2.2 | v2.3 |
| --- | --- |
| 字符串 `id/style_class` | `uint16_t id`；style class 删除 |
| `tinyui_widget_get_name_id()` | `tinyui_obj_get_id()` |
| `tinyui_widget_find_by_name_id()` | `tinyui_obj_find_by_id()` |

## 通用属性

| v2.2 | v2.3 |
| --- | --- |
| `tinyui_widget_set_pos()` | `tinyui_obj_set_pos()` |
| `tinyui_widget_set_size()` | `tinyui_obj_set_size()` |
| `tinyui_widget_set_text()` | `tinyui_obj_set_text()` |
| `tinyui_widget_set_bg_color()` | `tinyui_obj_set_bg_color()` |
| `tinyui_widget_set_text_color()` | `tinyui_obj_set_text_color()` |
| `tinyui_widget_set_border_color()` | `tinyui_obj_set_border_color()` |
| `tinyui_widget_set_radius()` | `tinyui_obj_set_radius()` |
| `tinyui_widget_set_padding()` | `tinyui_obj_set_padding()` |
| `tinyui_widget_set_visible()` | `tinyui_obj_set_visible()` |
| `tinyui_widget_set_enabled()` | `tinyui_obj_set_enabled()` |
| `tinyui_widget_destroy()` | `tinyui_obj_delete()` |

所有 setter 返回 `tinyui_result_t`。不支持的控件/属性组合返回 `TINYUI_ERROR_NOT_SUPPORTED`，不再只写 wrapper 镜像。

位置等 getter 改为 `result + out parameter`，不再用合法值 `-1` 表示错误。

文本 setter 从“保存调用者指针”改为复制字符串；调用者可在 setter 返回后释放原缓冲区。

## 事件

控件专用 callback 迁移到统一 API：

```c
tinyui_event_handle_t handle;
tinyui_result_t result = tinyui_obj_add_event_cb(
    button,
    TINYUI_EVENT_MASK(TINYUI_EVENT_CLICKED),
    on_button_event,
    user_data,
    &handle);
```

v2.3 事件同步直达 target：

- 不冒泡。
- 不 capture。
- 不排队。
- callback 来自固定容量池。
- 不再公开 `SIGNAL_*` 或 `tinyui_native_signal`。

删除 callback 时使用 generation handle，不能保存固定池索引。

## Focus 与 Key

| v2.2 | v2.3 |
| --- | --- |
| `tinyui_focus_reset(app)` | `tinyui_focus_clear()` |
| `tinyui_focus_navigate(app, native_dir)` | `tinyui_focus_move(tinyui_focus_direction_t)` |
| key state round-trip | UI 线程调用 `tinyui_input_send_key(key, pressed)` |

`tinyui_native_nav_dir` 不再公开。ENTER、BACK、方向键、NEXT、PREVIOUS 使用 TinyUI enum。

## Timer

| v2.2 | v2.3 |
| --- | --- |
| `tinyui_app_timer_create(app)` | `tinyui_timer_create(interval, repeat, cb, data)` |
| `tinyui_app_timer_start()` | `tinyui_timer_start()` |
| `tinyui_app_timer_stop()` | `tinyui_timer_stop()` |
| `tinyui_app_timer_destroy()` | `tinyui_timer_delete()` |

timer 来自固定容量池，不再逐帧创建 snapshot heap。

## Theme 与 Style

删除动态 `tinyui_theme_create/destroy()` 和字符串 `style_class`。

```c
static const tinyui_theme_t theme = {
    .colors = { /* 固定颜色表 */ },
    .metrics = { /* 固定 metric 表 */ },
};

tinyui_theme_set(&theme);
tinyui_theme_apply(screen);
```

临时 style 使用值 descriptor 立即应用，调用返回后可销毁 descriptor。TinyUI 不保存 style 指针，不做 selector 或级联。

## Flex 与 Grid

flex/grid container 参数统一为 `tinyui_obj_t *`。

grid 从裸负数 magic integer 改为 typed track：

```c
static const tinyui_grid_track_t columns[] = {
    { TINYUI_GRID_UNIT_PX, 80 },
    { TINYUI_GRID_UNIT_FR, 1 },
    { TINYUI_GRID_UNIT_CONTENT, 0 },
};

tinyui_grid_set_columns(container, columns, 3);
```

不再使用 END sentinel，最大 track 数为 16。

## Image 与 Font

图片 source 是调用者持有的轻量值：

- RGB565 memory。
- builtin。
- VRES。
- 可选 A8 mask。

ARGB8888 source 在直接 backend 适配闭环前返回 `NOT_SUPPORTED`。

字体只支持可直接映射的 builtin 与 VRES value；删除 family 字符串 fallback 和新的 glyph/provider 协议。

对象绑定期间 source/font 必须保持有效，解绑或对象删除后由调用者 deinit。

## 拼写与重复 API

| 删除名称 | canonical 名称 |
| --- | --- |
| `tinyui_tabel_show_keyboard` | `tinyui_table_show_keyboard` |
| `tinyui_scroll_selecter_*` | `tinyui_scroll_selector_*` |
| `tinyui_q_r_code_*` | `tinyui_qrcode_*` |
| `set_press` / `set_pressed` | 每项只保留一个 `set_pressed` 语义 |
| `set_select_item` / `set_selected_index` | `set_selected_index` |
| `set_msg` / `set_message` | `set_message` |

旧名称不进入 `tinyui.h`，也不承诺链接兼容符号。

## Native 边界

普通用户代码不得包含：

- `core/native.h`
- `internal/*`
- LingDongGUI 头
- Arm-2D 头

确有高级互操作需求时显式包含 native 扩展头；该路径不保证 TinyUI getter 与直接 native 修改同步。

## 迁移验收

每个迁移后的应用必须满足：

```sh
rtk rg -n 'tinyui_app_|tinyui_widget_|tinyui_native_|SIGNAL_|arm_2d_|#include .*internal' app_source
```

预期：除迁移说明或显式 native 扩展文件外零匹配。

应用还必须只通过安装后的 TinyUI target 编译，不添加 `tinyui/src`、LingDongGUI 或 Arm-2D private include path。
