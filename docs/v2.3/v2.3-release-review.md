### P1-001 — table `create_with_props` 镜像假成功（backend 映射 / 测试真实性）

| 字段 | 内容 |
| --- | --- |
| 严重度 | **P1** |

| 关联 | `tests/tinyui/unit/test_tinyui_table.c`（原断言 `backend->border_color/radius`）；`tinyui/demo/table_basic/table_basic.c` |

## 3. 维度详细结论

### 3.1 Backend 映射

- label/button/checkbox/slider/switch 等：setter 调用 `ld*Set*` 后写 cache。
- common adapter：`tinyui_runtime_internal_widget_set_bg_color/text_color` 有 kind 矩阵；无通道返回 -1。
- `tinyui_obj_set_border_color/width/radius` 公开返回 `NOT_SUPPORTED`。
- **例外已修**：table props 镜像路径。

### 3.2 生命周期与池

- 单实例 runtime；`delete_pending` 在 process/dispatch 结束 flush。
- timer/event 固定池；capacity 耗尽有错误路径。
- deinit 清 pool + theme borrow。

### 3.3 Descriptor

- `tinyui_image_source_t` / `tinyui_font_t` value 语义；pixels 指针借用。
- 32-bit ABI：image 72≤80、font 16≤16（lightweight-gates）。

### 3.4 安装 / demo / minimal

- install 树：`include/{tinyui.h,core,widgets,layout,theme,style,resource,integration}`，无 internal/port/src。
- demo boundary 与 removed API 门禁绿。
- minimal 符号门禁绿。

### 3.5 Port

- `port_completed=false` 贯穿 manifest / deferred-port / release-gates / manual-review。
- SDL 仅测试宿主；L6 不进 core。
