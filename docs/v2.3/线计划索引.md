## 固定顺序

```text
M0 事实基线
  -> M1 轻量公共契约
  -> M2 核心纵向闭环
  -> M3 全能力迁移
  -> M4 消费者与交付边界
  -> M5 硬化与冻结
```

禁止跳过 M0/M1 直接批量迁移控件。M2 的公共骨架和四个样板控件未闭环前，不得并行展开 M3。

## 阶段索引

### M0 事实基线

- 计划：`docs/v2.3/plans/stages/m0-truth-baseline-plan.md`
- 目标：修复全量构建，恢复 inventory、公共头、公共符号和轻量 baseline 的可信度。
- 关门条件：干净目录全量构建与全量 CTest 零失败，baseline 可重复。

### M1 轻量公共契约

- 计划：`docs/v2.3/plans/stages/m1-lightweight-public-contract-plan.md`
- 目标：冻结 runtime、object、result、event、timer、focus、style/theme、layout 和资源 value API。
- 关门条件：公共头 compile/link contract、裁剪配置和独立轻量性 review 通过。
- 状态：已完成（2026-07-14 closeout `DONE_WITH_CONCERNS`；仅允许声明 canonical 契约冻结、独立消费者可链接、轻量静态门禁与编译期裁剪已建立；不声明 L3-L5 / port / fixed_pool）。

### M2 核心纵向闭环

- 计划：`docs/v2.3/plans/stages/m2-core-vertical-plan.md`
- 目标：单实例 runtime、唯一 LingDongGUI tree、固定池和直接 setter adapter 闭环；label/button/checkbox/slider 达到 L1-L5。
- 关门条件：四个样板控件的 native、像素、事件、尺寸和分配证据通过。
- 状态：已完成（内部里程碑，`DONE_WITH_CONCERNS`）。M3 Task10 已重基 `v23_core_vertical` L5-V；四样板 L1–L5 与 `tinyui_m3_core` 内相关门禁可绿。不声明全控件、port、`fixed_pool` 或全量 demo/CTest 零失败。

### M3 全能力迁移

- 计划：`docs/v2.3/plans/stages/m3-full-capability-plan.md`
- 目标：全部控件、theme/style、flex/grid、image/font 和命名清理完成。
- 关门条件：required 达到 L4，可见/可操作能力达到对应 L5，轻量门禁不越线。
- 状态：**已完成（内部里程碑，`DONE_WITH_CONCERNS`）**（2026-07-15 Task 11 closeout）。`tinyui_m3_core` **55/55**、wrapper/steady-state/minimal/contract 绿；full-tree demo / 全量 CTest / binary·perf 指纹仍因 M4 签名债延期。不声明 port、`fixed_pool` 或发布完成。

### M4 消费者与交付边界

- 计划：`docs/v2.3/plans/stages/m4-consumer-delivery-plan.md`
- 目标：全部 demo、用户文档、安装包和仓外 C/C++ consumer 迁移。
- 关门条件：demo boundary、文档示例编译、install/export/find_package 和迁移检查通过。
- 状态：**已完成（内部里程碑，`DONE_WITH_CONCERNS`）**（2026-07-15 Task 8 closeout）。29 demo canonical、install consumer、docs examples、迁移指南 12 章、`v22_demo_bridge` 已删；SDL 仅测试宿主；port/L6 与全量 CTest/binary·perf 指纹仍延期到独立 port 线 / M5。不声明 v2.3 发布完成。

### M5 硬化与冻结

- 计划：`docs/v2.3/plans/stages/m5-hardening-freeze-plan.md`
- 目标：全量测试、安全测试、性能尺寸、能力矩阵、人工 review 和 ABI 冻结。
- 关门条件：无未关闭 P0/P1 非 port 问题，release gates 全部 fresh 通过。
- 状态：**内部里程碑 `DONE_WITH_CONCERNS`（2026-07-15 Task 8 closeout）**。ABI manifest 已冻结且 check PASS；release-evidence 齐；`abi_frozen=true`、`port_completed=false`、`manual_reviewed_passed=false`。最终聚合器因 gitnexus `fallback=true` 及 asan/ubsan/manual residual **诚实 FAIL**。**不得**声明 v2.3 已完成/可发布或 port/L6 生产可用。

## 共享写面

以下文件或真相源只允许单一集成任务修改：

- `tinyui/include/tinyui.h`
- 公共基础类型、结果码和 runtime 头
- `tinyui/src/core/widget.c`
- `tinyui/src/core/internal.h` 及 runtime internal 头
- native inventory、gap ledger、release matrix
- `cmake/LingDongGUI.cmake` 的 TinyUI 公共 target 定义

控件家族任务不得自行修改共享契约；需要变更时先回到集成任务重新裁边界。

## 状态维护规则

- 初始状态全部为“未开始”。
- 阶段施工中改为“进行中”。
- focused gate、broad gate、文档和独立 review 全部完成后改为“已完成”。
- 阶段失败保持“进行中”，不得写成“基本完成”。
- M5 之前不得写 `v2.3 已完成`。
