## 仍处过渡态

- `tinyui_*` 目前只覆盖试点 public surface；仓库仍保留大量 `tinyui/include/tinyui/*.h` public headers，不能写成“全量 public API 已切换完成”。
- `basic_widgets` 当前仍是 `tinyui_*` public API benchmark 与 runtime proof 载体，不能写成“官方 demo 已全部切到 tinyui_* 用户路径”。
- `tinyui/include/tinyui/app.h` 与 `tinyui/src/core/app.c` 仍在仓库中；当前已确认的是“用户主路径不再依赖 app”，不是“app 相关文件已完全删除”。
- `tinyui/src/backend/ldgui/` 下仍保留多份 `backend_*.c` 文件；当前已确认的是“shared architecture 被拆平、试点控件主路径已直连”，不是“backend 目录已整体消失”。
- `docs/v2.0/v2.0-performance-baseline.md` 明确把 `runtime_perf` 与 `wrapper_struct_overhead` 定义为窄口径 gate：
  - 不外推成完整首帧渲染时间
  - 不外推成整体 RAM 成本
  - 不外推成所有控件族的总性能结论
