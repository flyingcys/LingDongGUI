# TinyUI v2.0 Orchestration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在原位重整 `picoui/`，先消灭 `backend`，再消灭 `app`，最后收口 public API 与命名，同时保住已有 demos/tests/contracts。

**Architecture:** 按串行文档线执行迁移：`P0` 冻结 baseline 并加守门，`P1` 把 shared backend 职责搬进 `core`，`P2` 让试点控件走 `widgets -> ld*`，`P3` 用 LVGL-like runtime 入口替换 public `app` 模型，`P4` 收口 public API 与命名到 `TinyUI`，`P5` 独立量化性能/速度/RAM/二进制体积开销，`P6` 完成 docs/gates/release 真相收口。每个阶段都必须先过 focused tests + broad gates，再进入下一阶段。

**Tech Stack:** C11、CMake、SDL2、Arm-2D、现有 `LingDongGUI` core、当前 `picoui` demos/tests/contracts、Python gate scripts。
