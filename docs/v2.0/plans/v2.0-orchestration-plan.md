# TinyUI v2.0 Orchestration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在原位重整 `tinyui/`，先消灭 `backend`，再消灭 `app`，最后收口 public API 与命名，同时保住已有 demos/tests/contracts。

**Architecture:** 按串行文档线执行迁移：`P0` 冻结 baseline 并加守门，`P1` 把 shared backend 职责搬进 `core`，并只在必要时携带极少量非试点控件 lifecycle/ownership 修复以维持 shared/core flatten 后的既有 destroy 合同；`P2` 让试点控件走 `widgets -> ld*`，`P3` 用 LVGL-like runtime 入口替换 public `app` 模型，`P4` 收口 public API 与命名到 `TinyUI`，`P5` 独立量化性能/速度/RAM/二进制体积开销，`P6` 完成 docs/gates/release 真相收口。每个阶段都必须先过 focused tests + broad gates，再进入下一阶段。

**Tech Stack:** C11、CMake、SDL2、Arm-2D、现有 `LingDongGUI` core、当前 `tinyui` demos/tests/contracts、Python gate scripts。

当前阶段状态：

- `P0` 已完成 baseline inventory 与 transition guard 冻结
- `P1` 已完成 shared/core flatten closeout：focused tests `5/5 PASS`、`ctest -L tinyui` `50/50 PASS`、`git diff --check` clean、fresh review `APPROVED`
- `P2` 已完成试点控件拆平：`window/label/button/switch` direct `ld*` path、focused tests PASS、runtime/visible/backend mapping gate PASS
- `P3` 已完成 app-free runtime 主路径切换：`runtime.h/runtime.c` 落地、`basic_widgets` 改走 `init/screen/timer_handler`、focused/runtime/visible gate PASS
- `P4` 已完成 TinyUI public API 过渡：`tinyui/include/*` 落地、pilot runtime/switch/button alias 生效、transition/runtime/visible gate PASS
- `P5` 已完成性能、速度、RAM 窄口径与二进制体积守门：focused perf gates 与 runtime/visible/backend broad gates 已 fresh PASS
- `P6` 已完成 closeout、gates、docs 与 release-facing 真相收口；最终保守边界以 `v2.0-closeout.md`、`v2.0-release-matrix.md`、`v2.0-performance-baseline.md` 为准
