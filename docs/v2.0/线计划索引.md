## 本线定位

`v2.0` 不是新建一套最小 GUI，也不是整体 fork 一份 `LingDongGUI`。本线是：

- 以 `picoui/` 为施工现场
- 最大化复用现有代码、demo、tests、contract、构建
- 第一阶段先拆平 `backend`
- 第二阶段再消灭 `app`
- 后续再统一 `tinyui_*`
- 最终完成 `TinyUI` 目录、文档、产品名收口

## 固定顺序

固定顺序：

1. `P0` 基线冻结与守门
2. `P1` backend shared/core 拆平
3. `P2` window/label/button/switch 试点控件直连
4. `P3` `app` 主模型退场与 runtime 转换
5. `P4` `tinyui_*` public API 过渡与目录收口
6. `P5` closeout、gates、文档、release-facing 收口
