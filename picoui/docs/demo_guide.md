# PicoUI Demo 指南

## 推荐顺序

1. `picoui/demo/hello_world`
2. `picoui/demo/basic_widgets`
3. `picoui/demo/layout_flex`
4. `picoui/demo/layout_grid`
5. `picoui/demo/theme_showcase`
6. `picoui/demo/settings_panel`

## 说明

- `hello_world`：最小控件创建与文本设置
- `basic_widgets`：开关、复选框、滑条与回调入口
- `layout_flex`：`flex` 布局流向、对齐与间距
- `layout_grid`：`grid` 轨道、间距与单元格放置
- `theme_showcase`：theme v0 与文本/按钮组合
- `settings_panel`：props 双入口与组合布局示例
